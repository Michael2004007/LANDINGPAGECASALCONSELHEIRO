# Casal Conselheiro

Landing de Cristian e Kelly França, em português e espanhol.

## Executar

Requer Node.js 22 ou superior. Execute `npm start`. O servidor usa a porta de `PORT` ou 4173.

## Publicar no Railway

Conecte este repositório. O Dockerfile inicia o servidor sem dependências externas de aplicação. Gere um domínio público em Networking após o deploy.

- Estilos e adaptações responsivas em `dist/style.css`.
